# Item test pickups

These are deliberate test-only pickups. Drag any named prefab into BattleArena near your player spawn, then Play, join/start, and sail over it.

- SmokeScreen.prefab: collect and press LT/L2 (keyboard Shift). Move around inside the cloud; both players' boats and labels are hidden while inside.
- Underwater.prefab: collect and press LT/L2. Boat visuals disappear, firing is disabled, bubbles briefly reveal position, and the shared camera still frames both survivors.
- Offensive items activate with Square/X (keyboard E for the first keyboard player, Enter for the second), then fire with RT/click/Right Ctrl.

Each prefab lets you change the item, duration, respawn toggle and delay in the Inspector. Defaults: five-second item, eight-second pickup respawn. In Edit Mode the pickups use the existing chest art; in Play Mode they display the specific item's icon.

Faster alternative: Battle Mode > Item Tester. During Play Mode select a player and item, then Give and activate now. Default test duration is fifteen seconds. Normal item durations remain unchanged.

Remove these test pickups from the final arena when done.
